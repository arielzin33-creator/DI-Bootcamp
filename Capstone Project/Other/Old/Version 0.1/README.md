# Version 0.1 — Master Index

This folder holds three independent deliverables. Start here, then drill into the
relevant subfolder.

## `biz2code/`

The actual capstone project — a gated workflow that walks a business idea through
four human-approved phases and generates a Market Requirements Document, a Product
Requirements Document, and a Business Plan from the answers.

Everything project-related is nested inside: ADRs, architecture notes, the work
plan, question bank, benchmark data, seed data, and the service/schema source
files. See [`biz2code/FILE_INDEX.md`](biz2code/FILE_INDEX.md) for a file-by-file
index, and [`biz2code/README.md`](biz2code/README.md) if present, or
[`biz2code/ARCHITECTURE.md`](biz2code/ARCHITECTURE.md) for the system design.

> Note: `FILE_INDEX.md` documents a `client/` + `server/` split (React front end,
> Express back end) that hasn't been physically built out yet — the source files
> currently sit flat in `biz2code/`. Treat the documented paths as the intended
> structure, not yet the actual one.

## `AAAEE_Flowchart/`

A separate, earlier deliverable — not currently duplicated into this folder. The
source files live one level up, in the sibling `../Flowchart/` directory
(`AAAEE_Pipeline_Flowchart.html`, `.jsx`, `AAAEE_Pipeline_flow.json`, and the
deferred-layers spec `.docx`).
