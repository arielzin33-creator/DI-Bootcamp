# Tikal Code Challenge — Star Wars

Two independent solutions using [SWAPI](https://swapi.py4e.com/):

- **[part1-vehicle-population/](part1-vehicle-population)** — a Node script
  that finds which vehicle(s) have the highest sum of population across
  their pilots' home planets.
- **[part2-population-chart/](part2-population-chart)** — a React app with
  a hand-built (no charting library) bar chart comparing 5 planets'
  populations.

Each has its own README with setup instructions and the reasoning behind
its approach.

## Result summary (Part 1)

| Field | Value |
|---|---|
| Vehicle name with the largest sum | **Tsmeu-6 personal wheel bike** |
| Related home planets and their respective population | `[Kalee, 4000000000]` |
| Related pilot names | `[Grievous]` |
